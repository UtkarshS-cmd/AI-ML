=========================

Python/NumPy PDFs: code and task/context text were reconstructed from the PDF.
SQL PDFs: SQL queries were reconstructed and kept in code cells; task text is preserved as markdown.
Printed outputs from the PDFs are not pre-populated as outputs; run the cells to reproduce them.
